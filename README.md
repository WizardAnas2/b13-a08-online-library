### Project Overview: 
# Online Library is a comprehensive, full-stack web application designed for seamless book discovery and management. It provides a responsive user experience where readers can browse a diverse collection of books, filter by category, search for specific titles, and manage their personal profiles.

### Technologies used:

# 1. Next js App router , for server side rendering, efficient API handling.
# 2. Tailwind css and daisyUi for styling
# 3. Better-auth for login and registration
# 4. MongoDB for database
# 5. vercel for deployment

### Key features:
# 1. A responsive navbar
# 2. A search bar where users can find their books
# 3. user profile where users can update their profile information
# 4. secure registration and login feature
